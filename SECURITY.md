# Security and Privacy

This is a client-side Tampermonkey userscript. It reads QQ Music session information in the browser to query QQ Music's endpoint and uses MusicKit on the signed-in Apple Music website.

- Never submit account credentials, cookies, authorization tokens, backup JSON or matching reports to public issues.
- Review userscript permissions `GM_xmlhttpRequest` (limited to `u.y.qq.com`) and `unsafeWindow` (Apple Music MusicKit).
- The project does not intentionally send user information to developer-controlled servers.
- The current script depends on webpage behavior and unofficial QQ Music interfaces; changes to either platform may break it.
- For vulnerability reports, do not post secrets publicly. Open a sanitized issue to request a private contact channel.

This project is not affiliated with QQ Music, Tencent or Apple.
