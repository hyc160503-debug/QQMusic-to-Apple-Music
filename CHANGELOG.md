# Changelog

## 1.1.0-beta.2 — 2026-10-28

- Publish the Mac / Chrome Tampermonkey userscript to GitHub.
- Support exporting QQ Music liked tracks to JSON and CSV.
- Search Apple Music, compare candidate tracks, and create an Apple Music playlist after confirmation.
- Restore a previous matching report without repeating catalog searches.
- Support batch approval with a minimum similarity threshold; the default is 70% and can be changed.
- Apply PolyForm Noncommercial License 1.0.0.
- Beta caveat: unofficial QQ Music endpoint, catalog differences, and incorrect matches remain possible.

> The script is provided as-is; it has not been independently verified across multiple accounts or storefronts.
